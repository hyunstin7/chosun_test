3. 검증 제한
이 실행 환경의 Chromium 정책은 file:// 및 127.0.0.1 페이지 탐색을
ERR_BLOCKED_BY_ADMINISTRATOR로 차단했습니다.
따라서 파일의 HTML과 questions3.js 원문을 네트워크 없이 브라우저 문서에 넣어
동일한 UI 스크립트와 선택 이벤트를 검증했습니다.
외부 script 참조 경로는 별도의 파일 구조 검사로 확인했습니다.
사용자 PC에서 ZIP을 풀어 직접 여는 동작이나 실제 배포 URL에서의 로딩은 확인하지 못했습니다.
페이지 새로고침 후 실제 sessionStorage 기록 유지도 이 환경에서는 검증하지 않았습니다.
Nexacro Studio / 실제 Dataset 런타임에서 학습용 예제 코드를 실행한 검증은 아닙니다.
이번 작업은 승인된 코드·해설을 유지하고 문제 표시 및 채점 형식을 변경하는 작업입니다.
