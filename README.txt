넥사크로 — 코드 빈칸 객관식 수정본

실행: ZIP 전체를 해제하고 index.html을 엽니다.
교체: index.html과 quiz/questions3.js를 함께 덮어씁니다.
실제 파일명은 questions3.js입니다. question3.js라는 새 파일은 만들지 않았습니다.

수정 사항
- 직접 입력 방식은 제거했습니다. 답안 입력창·공백 비교·자기 채점 버튼이 없습니다.
- 예시 코드의 빈칸 3개에 들어갈 내용을 묶은 보기 4개 중 하나를 선택합니다.
- 코드 빈칸 객관식 23문항 + 예제 밖 보충 객관식 7문항 = 넥사크로 총 30문항.
- 선택 직후 정답/오답, 보기별 해설, 완성 코드를 표시합니다.
- 보기 순서는 문제를 불러올 때 섞이며, 해설과 정답도 해당 보기와 함께 매핑됩니다.
- 중복 선택에 의한 오답 중복 기록을 방지하고, 오답 복습·오답노트를 유지했습니다.

문제 파일 참조
index.html은 <script src="./quiz/questions3.js"></script>만 사용합니다.
question.js / questions2.js는 로드하지 않고, 이전 과목 데이터를 병합하지 않습니다.
전체 프로젝트 ZIP의 quiz 폴더에도 questions3.js만 들어 있습니다.
교체 ZIP으로 덮어쓰는 경우 예전 JS가 폴더에 남아 있어도 로드하지 않습니다.
